## 1.1 Коммерческие сайты

### Chemmed.ru (v2.0) — сайт медицинской тематики
- **Тип:** коммерческий
- **Назначение:** корпоративный сайт с каталогом и публичной частью.
- **Задачи:** вёрстка и интеграция шаблона, наполнение каталога, администрирование контента.
- **Стек:** ASP.NET Web Forms, Master Pages, jQuery, AJAX.
- **Демонстрирует:** поддержка и развитие legacy-проектов на Web Forms, работа с каталогом и админкой.

### Сайт макаронных изделий (СМИ) — сайт производителя
- **Тип:** коммерческий
- **Назначение:** сайт производителя макаронных изделий: каталог продукции, новости, фотогалерея, вакансии, обратная связь, гостевая книга.
- **Задачи:** разработка публичной части и админ-панели, авторизация, капча, работа с БД, развёртывание на хостинге.
- **Стек:** ASP.NET Web Forms (C#), SQL Server, jQuery, собственная админка, Master Pages.
- **Демонстрирует:** полноценный сайт «под ключ» — от БД и админки до публикации.

### Фасадные работы (OTFAS / ARM)
- **Тип:** коммерческий
- **Назначение:** автоматизированное рабочее место для компании, выполняющей фасадные работы: учёт заказов, расчёты, документы, работа офиса и выездных сотрудников.
- **Задачи:** проектирование доменной модели и БД, реализация внутреннего и внешнего контура (офис/подрядчики), расчётные модули, отчёты, роли и права, мобильный клиент, тесты, диагностика и починка серверной части у клиента.
- **Стек:** .NET 5, Blazor + Radzen, ASP.NET Core, EF Core (SQL Server), Identity, LinqSpecs, EasyNetQ/RabbitMQ, AutoMapper, NLog, MAUI, MSTest, миграции EF.
- **Особенности:** разделение на `ARM.UI.Inner` / `ARM.UI.Outer`, отдельные контексты данных, кэширование EF второго уровня, публикация и сопровождение.
- **Демонстрирует:** крупная бизнес-система: архитектура, БД, UI, мобильное приложение, тестирование, поддержка клиента.
